# 技能分类与计算逻辑

## 分类原则

技能按计算逻辑分类，每个类型对应一个独立的计算模块。分类依据是"这个技能怎么影响伤害/治疗的计算"，而不是技能的视觉效果或叙事描述。

一个干员可以有多个技能，每个技能独立分类。一个技能在不同等级可能保持同一类型，也可能跨类型（较少见）。

## 伤害公式基础

所有计算模块共用基础伤害公式：

```
物理伤害 = ATK × (100 / (100 + DEF))    最终伤害 = max(物理伤害, ATK × 0.05)
法术伤害 = ATK × (100 - RES) / 100      最终伤害 = max(法术伤害, ATK × 0.05)
真实伤害 = ATK                           无保底，全额伤害
```

## 干员面板计算（所有类型共用前置）

所有计算开始前，先根据用户选择的精英化/等级/信赖/潜能，计算出干员的实际面板值：

```
1. 根据精英阶段和等级，线性插值得到 base 值
2. 信赖加成：trust_value = trustBonus.属性 × trustPercent / 100
3. 潜能加成：叠加潜能固定值加成
4. A = base + trust_value + 潜能固定加成
5. 按 operator 字段叠加天赋效果（D_p/D_t/F_p/F_t）
6. panel = F_t × [(A + D_p) × (1 + D_t) + F_p]
```

后续各类型中“取干员面板 ATK”均指此计算结果。

## 类型一：持续增益型（DurationBuff）

**特征**：技能开启后持续一段时间，期间按倍率提升攻击力或改变攻击属性。

**典型干员**：银灰（真银斩）、陈（赤霄·绝影）、棘刺（至高之术）

**参数**：
- `atk_percent`: 攻击力百分比加成
- `def_percent`: 防御力百分比变化
- `attack_speed`: 攻击速度变化
- `attack_targets`: 攻击目标数
- `duration`: 持续时间
- `initialSp`: 初始SP
- `spCost`: SP消耗

**计算逻辑**：

```
前置：按 operator 字段计算干员面板值（来自 Wiki 属性基本公式）
  A_f = F_t × [(A + D_p) × (1 + D_t) + F_p]

  A   = base + 信赖加成 + 潜能固定加成
  D_p = Σ(直接加算类型的天赋/潜能 effect)
  D_t = Σ(直接乘算类型的天赋/潜能 effect)
  F_p = Σ(最终加算类型的天赋 effect)
  F_t = Π(最终乘算类型的天赋 effect)

1. 取干员面板 ATK（panel_ATK）
2. 计算技能期内的修正 ATK = base_ATK × (1 + atk_percent)
3. 真实攻击间隔 = baseAttackTime × (100 / (100 + attack_speed))
4. 技能期总攻击次数 = duration / 真实攻击间隔
5. 单次伤害 = 修正 ATK × (100 / (100 + DEF))  [物理]
6. 技能期总伤 = 单次伤害 × 总攻击次数 × min(攻击目标数, 敌方数量)
7. 技能期 DPS = 技能期总伤 / (技能持续时间)
8. 技能循环 DPS = 技能期总伤 / (技能持续时间 + SP冷却时间)
```

## 类型二：触发/回复型（TriggeredAttack）

**特征**：攻击回复SP，攒满后下次攻击造成倍率伤害。通常没有持续时间概念。

**典型干员**：银灰（强力击·γ型）、能天使（扫射模式）、大多数先锋的回费技能

**参数**：
- `atk_scale`: 攻击力倍率（如 2.9 = 290%）
- `spCost`: 触发所需SP
- `initialSp`: 初始SP

**计算逻辑**：

```
1. 取干员面板 ATK
2. 单次触发伤害 = ATK × atk_scale × (100 / (100 + DEF))  [物理]
3. 触发间隔 = spCost × 真实攻击间隔（攻击回复型）
4. 周期 DPS = 单次触发伤害 / 触发间隔
5. 非技能期 DPS = ATK × (100 / (100 + DEF)) / 真实攻击间隔
```

## 类型三：被动/光环型（PassiveAura）

**特征**：不主动释放，永久改变面板属性或提供范围加成。

**典型干员**：大部分天赋（攻击力+10%这种）、初雪（虚弱化）

**参数**：
- 各种 `xxx_percent` / `xxx_flat` 修改

**计算逻辑**：

```
被动效果在计算前叠加到面板上，不单独计算 DPS。

1. 取干员基础面板
2. 遍历生效的天赋/光环效果
3. 百分比类叠加：ATK = base × (1 + Σpercent)
4. 固定值类叠加：ATK = base + Σflat
5. 最终面板用于其他技能的计算
```

## 类型四：治疗型（Heal）

**特征**：技能期间恢复友方生命值。

**典型干员**：闪灵（圣光守护）、白面鸮（脑啡肽）、华法林（紧急治疗）

**参数**：
- `heal_percent`: 治疗量百分比加成
- `heal_flat`: 治疗量固定值加成
- `duration`: 持续时间
- `heal_interval`: 治疗间隔（通常等于攻击间隔）

**计算逻辑**：

```
1. 治疗基础值 = 干员 ATK（治疗者的攻击力决定治疗量）
2. 修正治疗量 = 基础值 × (1 + heal_percent) + heal_flat
3. 单次治疗量 = 修正治疗量
4. 技能期总治疗量 = 单次治疗量 × (duration / heal_interval)
5. HPS = 技能期总治疗量 / duration
6. 循环 HPS = 技能期总治疗量 / (duration + SP冷却时间)
```

## 类型五：多段攻击型（MultiHit）

**特征**：技能期间攻击间隔大幅缩短，或单次攻击发射多发弹体。

**典型干员**：能天使（过载模式）、灰喉

**参数**：
- `interval`: 技能期间的攻击间隔（覆盖基础值）
- `bullet_count`: 单次攻击的弹体数
- `atk_scale`: 每发弹体的攻击力倍率
- `duration`: 持续时间

**计算逻辑**：

```
1. 取干员面板 ATK
2. 每发伤害 = ATK × atk_scale × (100 / (100 + DEF))
3. 单次攻击总伤 = 每发伤害 × bullet_count
4. 总攻击次数 = duration / interval
5. 技能期总伤 = 单次攻击总伤 × 总攻击次数
6. 技能期 DPS = 技能期总伤 / duration
```

## 类型六：特殊机制型（Special）

**特征**：无法归入以上任何类型的技能，需要单独编写计算逻辑。

**典型干员**：阿（爆发剂·γ型，对友军造成伤害）、傀影（虚影）

**处理方式**：为每个特殊机制单独编写计算函数，在分类表中标注 `special` 类型。

## 技能分类表

在代码中维护一个分类映射表，将技能 ID 映射到对应类型：

```javascript
const SKILL_TYPE_MAP = {
  // 银灰
  "skcom_attack_def": "TriggeredAttack",    // 强力击·γ型
  "skchr_silvr_2": "DurationBuff",          // 雪境生存法则
  "skchr_silvr_3": "DurationBuff",          // 真银斩

  // 能天使
  "skchr_amiya2_1": "TriggeredAttack",
  "skchr_amiya2_2": "MultiHit",
  "skchr_amiya2_3": "MultiHit",             // 过载模式

  // 闪灵
  "skchr_slbell_2": "Heal",

  // ...逐步扩展
};
```

未在表中的技能默认标记为 `unknown`，UI 上提示"该技能暂不支持计算"。

## 天赋处理

天赋的 effects 数组在计算前统一叠加到面板上：

```
1. 读取干员当前精英阶段
2. 筛选该阶段生效的天赋 candidate
3. 遍历 effects，按 type 叠加到基础面板
4. 得到修正后的面板，供后续技能计算使用
```

天赋的 `talent_enhance` 类型（潜能5的效果）需要特殊处理：提升的是天赋本身的数值，不是直接修改面板。

## 扩展新技能类型的流程

1. 在 `docs/skill-types.md` 中定义新类型的参数和计算逻辑
2. 在 `src/calculator/` 中创建对应的计算模块
3. 在 `SKILL_TYPE_MAP` 中添加技能 ID 到类型的映射
4. 添加单元测试验证计算正确性
