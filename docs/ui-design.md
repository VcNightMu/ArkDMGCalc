# 界面设计

## 设计原则

- **功能优先**：所有信息一目了然，不需要翻页或弹窗
- **数据密集**：计算器类产品，信息密度高是正常的，但要有层次
- **对比方便**：多干员结果并排展示，便于比较

## 交互流程

1. **搜索干员**：输入框支持中文名/英文名模糊搜索，下拉列表显示头像+名字+职业
2. **添加干员**：点击搜索结果或直接点击热门干员卡片，添加到当前对比列表
3. **配置干员**：选中已添加的干员，下方展开该干员的精英化/等级/技能配置
4. **填写敌人**：右侧敌人数据区域直接输入数值
5. **计算**：点击计算按钮，下方展示所有干员的计算结果并排对比
6. **移除干员**：点击干员头像上的 × 按钮移除

## 颜色方案

采用明日方舟 UI 风格，深色背景 + 浅色文字：

- 背景色: `#1a1a2e` (深蓝黑)
- 卡片背景: `#16213e` (深蓝)
- 强调色: `#e94560` (方舟红)
- 文字色: `#eaeaea` (浅灰白)
- 数值高亮: `#0f3460` (深蓝亮)

## 响应式

窗口最小尺寸 1200×800，不考虑移动端。Tauri 窗口固定比例即可。
