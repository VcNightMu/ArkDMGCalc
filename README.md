# ArkDMGCalc - 明日方舟干员伤害计算器

基于 Tauri 的桌面端干员伤害计算器。填入敌人数据，基于干员技能计算技能期总伤/DPS、非技能期DPS、触发类周期DPS、治疗HPS/总治疗量。

## 技术栈

- **框架**: Tauri v2（Rust 后端 + Web 前端）
- **前端**: HTML + CSS + JavaScript（ Vanilla 或轻量框架，视开发需要）
- **数据源**: PRTS Wiki（prts.wiki）
- **本地存储**: JSON 文件
- **打包**: 单个 .exe 可执行文件

## 功能概览

- 干员选择（搜索 + 头像展示）
- 精英化阶段 / 等级 / 信赖（0-100%）选择
- 技能选择（等级 1-7 + 专精 1-3）
- 敌人数据输入（生命 / 攻击 / 防御 / 法术抗性）
- 最多同时 5 个干员对比
- 计算结果展示：
  - 输出类干员：技能期总伤、技能期DPS、非技能期DPS
  - 触发型干员：单次触发伤害、周期DPS
  - 治疗类干员：HPS、技能期总治疗量

## 数据更新策略

- 程序启动时检查更新时间，超过阈值自动在后台静默更新
- 不提供用户手动触发的"立即更新"按钮（防止对 Wiki 造成过大请求压力）
- 抓取频率控制在合理范围内，每次更新间隔不低于 24 小时
